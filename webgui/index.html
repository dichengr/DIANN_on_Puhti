Group DIA-NN pipeline · HPC cluster

Set up a DIA-NN run without writing any code

Fill in four paths, paste the settings from your own DIA-NN, and this page writes the configuration file for you. You never edit a file on the cluster — you only copy, paste and press Enter.

01Your files 02Settings 03Config file 04Run it

Nothing on this page talks to the cluster. It only writes text for you to paste, so you can safely try things out.

01

Where are your files on the cluster?

Paths must be the ones on the cluster — they always start with a /, never with C:\. Open the folder in the cluster's file browser and copy the path from the address bar.

Project

Used to name your config file. Letters, numbers and underscores.

Your data

Folder(s) containing your raw files

The folder that contains the .d or .raw files — not a single file. Add more folders to analyse several batches together.

Created if it does not exist. Suggested beside your data folder, named after this run Created if it does not exist. Suggested from your data folder — change it if you like.mdash; change it if you like.

Reference files

The starting library for the first search. Ends in .speclib, .parquet or .tsv.

Ends in .fasta or .fa.

The .sif container file for the DIA-NN release you want. New versions appear often — check the 01_containers folder to see which are available, and use the same one across a project so results stay comparable.

Advanced — you can usually skip this

Clusters cap how many jobs one account may queue. With more raw files than this, the run is split into batches automatically. Leave at 350 unless you have been told otherwise.

Check the paths are right

This page cannot see the cluster, so it cannot confirm your paths exist. Copy this one line, paste it into a terminal and press Enter — it checks every path, counts your raw files, and prints a short report.

terminal — check paths

Put it on the cluster

    

      Copy this one line, paste it into a terminal and press Enter. It writes the file for you
      and confirms where it went — no editing, no file transfer. The scrambled text is
      your config encoded, so nothing in your paths can be mangled on the way in; the readable
      version is right above.
    

    

      

        terminal — write the config file
        
      

      

    

    

      
    

    

      

        Prefer pasting. A file downloaded on Windows carries invisible line
        endings that make the cluster fail with $'\r': command not found. If you do
        download and upload it, run sed -i 's/\r$//' yourfile_config.sh once
        afterwards to clean it.
